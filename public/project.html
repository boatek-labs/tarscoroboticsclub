3-DOF Robotic Arm with Inverse Kinematics

A 3-degree-of-freedom robotic arm built from scratch using 3D-printed joints, MG996R high-torque servos, and an Arduino Mega 2560. Implements basic inverse kinematics for smooth, precise end-effector positioning. Controlled via joystick with real-time angle readouts on the serial monitor.

arduino-mega servo inverse-kinematics 3d-printing mechanical joystick
Problem / Purpose

Manual pick-and-place tasks in robotics competitions are often handled by rigid, pre-programmed arms that can't adapt to varying object positions. This project aimed to build a 3-DOF arm that calculates joint angles from a desired end-effector position in real time — making it adaptable and competition-ready without reprogramming for each scenario.

Code
Full commented sketch below. The inverseKinematics() function converts target X/Y coordinates into joint angles using trigonometric relations.
robotic_arm.ino
// TRC — 3-DOF Robotic Arm with Inverse Kinematics // Team: Esi D., Jerry D., Michael A. | 2025 #include <Servo.h> #include <math.h> // Arm segment lengths (cm) const float L1 = 12.0; const float L2 = 10.0; Servo base, shoulder, elbow; void setup() { base.attach(2); shoulder.attach(3); elbow.attach(4); Serial.begin(9600); } void loop() { int joyX = analogRead(A0); int joyY = analogRead(A1); // Map joystick to target coordinates float targetX = map(joyX, 0, 1023, -20, 20); float targetY = map(joyY, 0, 1023, 2, 20); inverseKinematics(targetX, targetY); delay(20); } void inverseKinematics(float x, float y) { float d = sqrt(x*x + y*y); if (d > L1 + L2) return; // out of reach float cosA2 = (d*d - L1*L1 - L2*L2) / (2*L1*L2); float theta2 = acos(cosA2); float k1 = L1 + L2*cos(theta2); float k2 = L2*sin(theta2); float theta1 = atan2(y,x) - atan2(k2,k1); int ang1 = constrain(degrees(theta1), 0, 180); int ang2 = constrain(degrees(theta2), 0, 180); shoulder.write(ang1); elbow.write(ang2); Serial.print("θ1: "); Serial.print(ang1); Serial.print(" θ2: "); Serial.println(ang2); }

Build Steps
1
Print & Assemble the Arm Structure

3D print the 4 joint parts in PLA at 30% infill. Attach servo horns to each joint before assembling. The base servo mounts on the bottom plate, shoulder at joint 1, elbow at joint 2.

2
Wire the Power Circuit

MG996R servos draw up to 2.5A stall current each. Never power them from the Arduino 5V rail. Use the LM2596 step-down to get 6V from your 12V supply. Connect servo power rails to this output and share GND with the Arduino.

3
Connect Servos & Joystick

Servo signal wires → Arduino pins 2, 3, 4. Joystick VCC → 5V, GND → GND, VRx → A0, VRy → A1. Double-check shared grounds between servo power supply and Arduino.

4
Upload & Calibrate

Upload the sketch. Open Serial Monitor at 9600 baud. Move the joystick slowly and observe θ1/θ2 values. If servos jitter, add a 100µF capacitor across the servo power rails. Adjust L1/L2 constants in code to match your printed arm dimensions exactly.

5
Test & Iterate

Test the full range of motion. If the elbow servo strains at full extension, reduce the max target Y in the map() call. Consider adding a gripper servo on pin 5 for pick-and-place capability.
